# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be respectful, assume good faith, give and accept constructive feedback, and keep
discussions about the work. Harassment of any kind is not tolerated.

Report unacceptable behaviour privately to the maintainers (see `SECURITY.md` for the contact
channel). Maintainers may remove comments, issues or contributions that do not follow this code
and may ban contributors who repeatedly violate it.
