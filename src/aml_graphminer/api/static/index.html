Chargez un fichier de transactions (CSV, JSON ou Parquet, au format IBM AML ou canonique : timestamp, sender, receiver, amount…) ou générez un jeu de démonstration synthétique contenant des motifs de blanchiment injectés.

Chaque jeu est analysé à son arrivée : les détecteurs de motifs structurels (fan-in, fan-out, smurfing, cycles, scatter-gather, gather-scatter, communautés à risque) produisent des alertes, et le modèle chargé attribue un score à chaque transaction.
